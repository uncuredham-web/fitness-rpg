# 【引き継ぎ書】運動モチベーション維持用：ハクスラ風RPG Webアプリ開発プロジェクト

## 1. プロジェクト概要・目的
- **目的**: 日々の運動のモチベーション維持のため、運動量を入力して遊ぶシンプルなハクスラ風RPGの自作Webアプリ。
- **身体状況・方針**: 開発者は現在「五十肩」のリハビリ中のため、最初は「ウォーキング」と「ストレッチ」のみで運用。肩の回復後に「バッティング（球数）」を解禁する段階的デザインを採用。
- **利用環境**: PC・スマホ両対応（GitHub Pagesで公開し、スマホの「ホーム画面に追加」でアプリ風に利用）。

## 2. 現在の技術スタック・ファイル構成（全5ファイル / UTF-8）
フレームワーク不使用のバニラHTML / CSS / JS構成で、ビルド不要・保守性重視。
1. `index.html`: 画面骨格（冒険・記録画面、図鑑・累計実績画面のタブ切り替え、初期化・URL同期UI）。
2. `style.css`: 明るいスポーツRPG調のデザイン（スカイブルー＆オレンジ基調、片手操作しやすいボタン配置）。
3. `data.js`: マスターデータ定義。Googleスプレッドシートを「ウェブに公開（CSV）」したURL（`SHEET_CSV_URL`）から、`rarity` / `option` / `item` を起動時に自動取得（オフライン用フォールバック付き）。
4. `app.js`: ゲーム計算ロジック、`localStorage`（キー名：`hakusura_fitness_save_v2`）への自動保存・復元。
5. `ui.js`: DOM操作、イベント制御、Base64エンコードによる「引き継ぎ用URL（`?save=...`）」生成・復元処理。

## 3. 現在のゲームシステム仕様
- **前日の睡眠時間（バフ）**: 「6時間未満（0%）」「6〜7時間（+15%）」「7.5時間以上（+30%）」をタップで記録。その日の会心率・レア発見率にバフを付与。
- **夜の一括入力・冒険実行**: 1日の終わりに運動量をまとめて入力し、「まとめて冒険に出発する！」ボタン1回で全種目を一括処理。
  - **ウォーキング（分）**: 「探索」担当。距離加算＋「防具・お守り」がドロップ。
  - **ストレッチ（分）**: 「基礎戦闘」担当。精密攻撃判定＋「武器（木刀・素振りバット等）」がドロップ。
  - **バッティング（球）**: 「上位戦闘」担当（UI上のチェックボックスでロック解除可能）。高倍率攻撃＋「高レア武器（金属バット等）」がドロップ。
- **コンボ＆自動変換システム**:
  - 1日に2種目以上入力すると「コンボボーナス（強化石＋獲得EXP1.2倍）」が発動。
  - ドロップ装備が現在の装備より強ければ自動更新し、古い装備（または弱いドロップ品）は自動で「強化石」に変換。強化石を消費して各部位を直接パワーアップ可能。
- **図鑑・累計実績**: 総冒険回数、累計歩行距離、累計ストレッチ時間、累計バッティング球数、発見済み装備のカタログ保存・閲覧機能。
